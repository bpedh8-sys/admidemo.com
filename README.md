# Standalone Admin Demo (GitHub Pages)

This demo runs as a single static HTML page and stores its sample data in the visitor's browser Local Storage. It does not require Supabase or a backend.

## Deploy with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` (and optionally this README) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and open the URL shown in the Pages section.

Note: Local Storage is browser/device-specific. Demo entries won't sync between users or devices.
